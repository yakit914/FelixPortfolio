# Portfolio for a Friend

An HTML, CSS, and JavaScript web application built to display my friend's professional resume. I created this as my first project while learning web development to practice coding a layout from scratch.

## Features

- Displays my friend's career experience and profile
- Works on both desktop and mobile screens

## How to View

1. Open the `index.html` file in any web browser.
